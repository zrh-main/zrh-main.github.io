懒加载(延迟加载)

Java 持久层框架
mybatis
发布日期:   2022-02-11

概述

延迟加载：在真正使用数据的时候才发起查询，不用的时候不查询关联的数据，延迟加载又叫按需查询（懒加载）
立即加载(积极加载)：不管用不用，只要一调用方法，马上发起查询

使用及案例

案例简介:
一个用户下有多个账户
表关系:一对多
需求:查询所有用户的信息;需要时,查询该用户下的账户信息
案例分析:

需要两个实体类(pojo)
