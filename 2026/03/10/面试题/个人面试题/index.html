个人面试题
面试题
发布日期:   2026-03-10

自我介绍

我是张荣辉，求职 Java 开发工程师，有 多年的 Java 开发经验。
熟练掌握 Spring Cloud Alibaba 微服务架构，能熟练运用 Redis、RabbitMQ、ES 等主流中间件，擅长 MySQL 优化、Linux 环境部署与问题排查，也会 Vue 做前后端联调。
先后任职于飞沐网络、斯锐信息，核心参与元数据平台、航天云膜、青松职考等项目，落地过高并发库存扣减、50 万条脏数据修复，能独立负责模块开发，也具备线上问题排查能力，能够快速承接 Java 开发的任务

写过技术文档吗?怎么写的

在航天云膜项目中，我编写过 “库存扣减接口” 的技术文档。
在结构上，采用 “接口概述 - 请求说明 - 响应说明 ” 的固定框架，让读者能快速定位信息。
接口概述明确用途和适用场景；
请求说明分必填 / 可选参数，列出字段名、类型、示例和约束；
响应说明用表格展示状态码、message 含义及 data 结构；

职业规划

1-2 年内快速熟悉公司业务和技术架构，将实战经验落地，解决业务中的技术问题，成为团队核心开发人员

离职原因

离职主要是因为之前外派合作的研究所管理层调整，后续对接的东软相关项目还未确定，导致后续工作内容和方向不明确；另外也考虑到武汉的工作竞争压力更小、工作节奏更舒缓，更适合长期稳定发展

  1. 从上一家离职的原因？
    我之前在北京工作 6 年，现在打算定居武汉，所以找本地的 Java 开发岗。也想在武汉的优质业务场景里继续深耕微服务、高并发技术，不是前公司的问题，那边的项目和团队都挺靠谱的。
  2. 未来 3-5 年的职业规划？
    短期 1-2 年想快速融入团队，把微服务、中间件的实战经验落地，做独当一面的核心开发；3-5 年往技术架构师走，参与架构设计、性能优化，同时持续学云原生这些新技术，保持技术敏感度。
  3. 你的核心优势是什么？
    一是技术落地能力强，6 年 Java 开发，微服务、Redis/ES/MQ 这些高并发实战都有积累，能解决实际生产问题；二是排查和优化意识强，不管是 SQL 还是接口调优，都有不少落地案例，能快速定位线上问题。
  4. 目前的不足 / 待提升的地方？
    云原生比如 K8s、容器化部署，生产环境的实战经验还不够，大型微服务治理这块也想多学。不过我已经在自学 K8s 了，后续也会考相关认证，尽快把这块短板补上。
  5. 怎么看待加班，能接受吗？
    项目上线、线上故障这种紧急情况的加班我能接受，之前做项目也有过集中加班，都顺利完成了。但我更注重工作效率，尽量在工作时间把事做好，避免无效加班，紧急情况肯定全力配合团队。
  6. 和同事 / 领导意见不合怎么解决？
    遇到过，比如之前做数据处理，和同事对方案有分歧。当时我们对事不对人，一起梳理业务、做技术验证，最终敲定兼顾效率和数据安全的方案。核心就是以业务和技术可行性为标准，沟通验证达成共识。
  7. 期望薪资 13k-15k，怎么定的？
    结合武汉本地同经验 Java 开发的薪资水平，还有我 6 年的实战经验，做过多个行业核心项目，能独立做模块设计和性能优化，这个区间是比较合理的，也希望公司根据我的实际能力综合考量。
  8. 入职后多久能独立开展工作？
    如果是 Spring Cloud Alibaba+Redis/ES 这套主流技术栈，1-2 周熟悉业务和流程，2 周就能独立做模块开发；有新技术的话我业余快速学，保证 1 个月内独立开展工作。
  9. 拿到 offer，多久能到岗？
    我已经从上家离职了，现在就在武汉，入职手续也能提前准备好，一周内就能到岗，保证顺利入职。
  10. 平时怎么提升自己的技术能力？
    平时看掘金、官方文档学新技术，比如现在学云原生；也会复盘过往项目，总结优化和分布式的实战经验；还会看技术书籍，把学到的内容落地到小项目里，保证学用结合，跟上技术更新。
  11. 你还有什么问题要问我吗？
    想请教三个问题：一是这个岗位所在研发团队的规模和目前的技术难点；二是公司对这个岗位的短期和长期工作要求；三是公司的技术培训和晋升机制是怎样的？
  12. 你现在有 offer 了吗？是 offer 不合适才没去吗？
    目前手里有 1-2 个意向 offer，不过还在综合考虑，不是之前的 offer 不合适，还是希望能找到长期发展的平台
