如果数据不存在，则作为新数据添加；如果数据已经存在，则更新旧数据。那么我们可以添加参数 doc_as_upsert

POST student-001/_update/1?refresh=true

{
  "doc": {
    "name": "student-23"
  },
  "doc_as_upsert": true
}
